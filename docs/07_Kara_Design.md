# 🎨 Kara Design: Sovereign Vector Graphics & Layout Tool

## Chapter 1: Introduction & Core Purpose
Kara Design is a lightweight, offline-first alternative to Canva and Figma. It allows you to create logos, banners, social media graphics, and slide assets without sending your creative work to the cloud.

## Chapter 2: Key Features & Functionalities
- **AI Design Assistant**: Describe a layout (e.g., "A red circle with white text saying Hello") and local AI generates the vector JSON instantly.
- **Drag, Resize, & Layer**: Full manual control. Drag shapes, resize via the bottom-right handle, and use Up/Down arrows to change stacking order.
- **Quick Templates**: One-click starters for Social Posts, Banners, and Logos.
- **Image Upload**: Import external logos or photos to include in your canvas.
- **Native PNG Export**: Renders the canvas to a crisp .png file using the browser's native Canvas API (zero dependencies).

## Chapter 3: Step-by-Step Usage Guide
1. **Open**: Select "Kara Design" from the sidebar.
2. **AI Generate**: Type a prompt in the purple AI box and press Enter. Watch the shapes appear.
3. **Manual Refine**: Click any shape to select it. Use the color picker to change its color, or drag the white corner dot to resize it.
4. **Add Image**: Click the green Image icon in the toolbar to upload a local file.
5. **Export**: Click "Export as PNG" at the bottom of the sidebar to download your creation.

## Chapter 4: Intersections & Ecosystem Integration
- **To Kara Slides**: Export your design as a .png, then conceptually use it as a custom background or logo in your Kara Slides presentations.
- **To Kara Word**: Exported PNGs can be inserted into formal reports generated via Kara Intelligence.
