# 📊 Kara Sheets: Sovereign Spreadsheet & Quant Engine

## Chapter 1: Introduction & Core Purpose
Kara Sheets is a high-performance, local-first spreadsheet application designed for data analysis, financial modeling, and tabular data management. It replaces Excel while adding sovereign AI capabilities.

## Chapter 2: Key Features & Functionalities
- **Dynamic Grid**: Fast, virtualized grid supporting hundreds of rows and columns.
- **Quant Mode**: Built-in advanced financial formulas (Black-Scholes, Greeks) for institutional-grade modeling.
- **CSV Import/Export**: Seamlessly bring in external data or export your work for external sharing.
- **Local Intelligence**: Publish sheet data directly to the Kara Intelligence bus for AI summarization.

## Chapter 3: Step-by-Step Usage Guide
1. **Open**: Select "Kara Sheets" from the sidebar.
2. **Input Data**: Click any cell to type data or formulas.
3. **Import**: Click "Import CSV" in the toolbar to load an existing dataset.
4. **Analyze**: Use the Quant Mode toggle to access advanced financial functions.

5. **Export**: Click "Export CSV" to save your grid as a universal file.

## Chapter 4: Intersections & Ecosystem Integration
- **To Kara Base**: Structured tabular data from Sheets can be exported as CSV and imported directly into Kara Base to become a relational database.
- **To Kara Intelligence**: Click "Publish" to send your sheet's data to the Intelligence drawer, where AI can generate executive summaries or risk reports.
