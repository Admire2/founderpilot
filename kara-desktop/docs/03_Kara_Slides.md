# 📽️ Kara Slides: Sovereign Presentation Deck Builder

## Chapter 1: Introduction & Core Purpose
Kara Slides is a privacy-first presentation builder. It allows you to create, edit, and export professional slide decks without relying on cloud-based tools like PowerPoint or Canva.

## Chapter 2: Key Features & Functionalities
- **AI Deck Builder**: Generate entire slide decks from a single text prompt using local AI.
- **Multi-Format Import**: Import .pdf or .docx files to automatically convert them into editable slides (one slide per page/section).
- **Flexible Layouts**: Choose between Title, Content, and Split layouts for each slide.
- **Native Export**: Export your finished deck as a themed, multi-page .pdf or raw .html.

## Chapter 3: Step-by-Step Usage Guide
1. **Open**: Click "Kara Slides" in the sidebar.
2. **Create**: Click "+" to add a new slide. Select a layout from the right panel.
3. **AI Generate**: Type a topic (e.g., "Q4 Financial Review for Dangote") in the AI prompt and click "Generate Deck".
4. **Edit**: Click on any text box to modify titles or bullet points.
5. **Export**: Click "Export PDF" to download a board-ready presentation file.

## Chapter 4: Intersections & Ecosystem Integration
- **From Kara Design**: Backgrounds or logos created in Kara Design can be exported as .png and conceptually referenced (future V2.1 will allow direct asset embedding).
- **From Kara Intelligence**: Select a "Combined Report" in the Intelligence drawer and click "To Slides" to instantly convert an AI-written report into a formatted presentation.
