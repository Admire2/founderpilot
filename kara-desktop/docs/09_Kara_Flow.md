# ⚡ Kara Flow: Sovereign Project & Task Management

## Chapter 1: Introduction & Core Purpose
Kara Flow is a Kanban-style project management tool (similar to Trello or Linear). It helps teams or individuals track tasks, assign owners, and monitor progress without relying on external SaaS platforms.

## Chapter 2: Key Features & Functionalities
- **Kanban Board**: Visual columns for "To Do", "In Progress", and "Done".
- **Task Metadata**: Assign titles, assignees, and due dates to every card.
- **Local Persistence**: All boards and tasks are saved instantly to your device's local storage.
- **Quick Actions**: One-click movement of tasks between columns, or instant deletion.

## Chapter 3: Step-by-Step Usage Guide
1. **Open**: Select "Kara Flow" from the sidebar.
2. **Create Task**: Use the top input bar to type a Task Title, Assignee, and Due Date. Click "Add".
3. **Manage**: Drag and drop is simulated via the "← Back" and "Forward →" buttons on each card (V2.1 will add native drag-and-drop).
4. **Complete**: Move tasks to "Done" to track project velocity.

## Chapter 4: Intersections & Ecosystem Integration
- **From Kara Base**: Action items identified in a Kara Base database can be manually recreated here as trackable tasks.
- **Via Kara Connect**: (Future V2.1) A rule can be set: "When Kara Mail receives an email with 'Action Required' → Create a Kara Flow task."
